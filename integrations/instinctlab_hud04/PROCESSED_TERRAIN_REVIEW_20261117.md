## 三维表面查询与候选区间（不是接触标签）

使用每个胶囊的**完整轴段**到裁剪后三角面的最小无符号距离，再减半径：

`surface_margin = min distance(axis_segment, triangle_surface) - radius`。

端点到面、边到边、轴段穿面均参与；AABB 下界只用于安全排除不可能更近的面。
另对全部近侧向面做独立查询，不将垂向上包络误当侧墙碰撞距离。
名义胶囊伸入三角面时 margin 可为负，但它**不是有符号实体穿透深度**；
正 margin 也不能排除包含关系，不能代表 HUD04 或整机无碰撞。

每个假设、每个连杆的逐帧最小 margin 和几何近面候选区间已写入
`PROCESSED_TERRAIN_SURFACES_20261117.json`，仅限 `[611,641]`、`[659,689]`、
`[711,741]` 三个闭区间；区间合并不会跨过未采样帧。
阈值 `abs(margin)<=0.020` 仅为**原始单位的诊断带**，不是已验证的米制接触容差。

下表为每个连杆至少一个胶囊进入该带的帧数，每项分母为 93；不代表支撑时长：

|---|---:|---:|---:|---:|---:|---:|
| torso_link / wxyz | 73 | 35 | 0 | 0 | 15 | 9 |
| pelvis / wxyz | 0 | 61 | 25 | 0 | 31 | 6 |
| torso_link / xyzw | 0 | 0 | 0 | 0 | 0 | 0 |
| pelvis / xyzw | 0 | 0 | 0 | 0 | 0 | 0 |

近侧向面查询在全部假设/选帧中均未进入 `0.020` 带。
四种假设的最小 lateral margin 依次为 **0.330246280、0.156619002、
0.112114274、0.330462173**（原始单位）。不能据此断言完整技能无侧墙接触：
仍有未采样帧、未选坐标、未验单位、源/目标模型差异及真实接触动力学待确认。
尤其不能因某假设“没有负间隙”或“更少近面点”就选它。

独立复核选取每假设×每连杆的最小 margin 见证，共 **24 个**；
每个见证对全表面和侧向面分别核验，共 **48 项**。
独立算法不使用自定义线段/三角形分解或 AABB 筛选：对每个三角形，使用 trimesh
点到三角形算法，沿轴段独立做 65 步凸一维最小化，并比较端点，最后全局取最小。
最大误差：全表面 **8.674537101566616e-14**、侧向面 **3.3306690738754696e-16**。
这不是独立重算所有 6696 次表面查询；完整解析/随机/刚体变换回归另由 CPU 测试覆盖。
**150 项 CPU 测试全部通过**，仍不等于仿真或动作验收。
