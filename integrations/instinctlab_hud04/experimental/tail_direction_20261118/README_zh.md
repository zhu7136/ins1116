- 144次有界稀疏LP，144次非线性角度目标下降更新，覆盖全部997帧；算法15.35秒，
  含加载和独立复算的受监控子进程16.10秒，正常退出，无重试/后台调用。
- 预设8轮、每轮17个93帧重叠窗口；第4/8轮各补4个由输入固定选择的尾部窗口。
  窗口内及两侧相邻帧的原速度限值均为硬约束，最后直接检查全部996条边。
- 原始目标函数：角度总和 + 10倍超过25°部分总和 + 100倍全局最大角度 +
  0.001倍相对输入关节位移L1。信赖步长0.15rad。实际非线性目标下降且全局最差
  不增加才接受；无事后关节剪裁、无放宽速度、无改帧率/丢帧。
- 两线程，单LP上限1秒，算法总上限90秒，子进程110秒回收；本轮预算已结束，
  **不得直接再次执行本launcher或把这144次预算当成继续追加迭代的授权**。

  角度与报告最大差5.78e-14°；再次从原URDF独立读29关节限值：位置越界0，
  最大速度浮点残差2.94e-9rad/s（数值容差1e-6）。头yaw/pitch fixed与零位再次检查。
